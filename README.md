# expert-book

Локальная книга «Методы подготовки эксперта».

Запуск из корня проекта:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Открыть http://127.0.0.1:4173/ . Исходники находятся в `dist/`; сборка не требуется.

Шесть содержательных разворотов: титульный лист, история возникновения, добродетели эксперта, рыцари круглого стола, испытание боем и защита перед советом ордена. Гравюры установлены; тексты глав предварительные.

Первое состояние — закрытая кожаная книга без надписей, с тонкой рамкой и небольшим тиснением. Клик или стрелка вправо открывают передний форзац; следующее перелистывание открывает титульный разворот. После последней главы идут задний форзац и закрытие. Любой переход обратим. Home / End ведут к обложкам, оглавление — прямо к выбранной главе.

Хеши `#cover`, `#back-cover` — обложки; `#front-endpaper`, `#back-endpaper` — форзацы. Ссылки на главы сохранены. Форзацы не добавляют глав и не меняют нумерацию контента. На узком экране видна одна страница. Анимация учитывает уменьшение движения и безопасно завершается при изменении размера окна.

Переплёт: `dist/book-covers.js` и `dist/book-covers.css`. Активная наружная текстура — `dist/assets/antique-cover-v3.png`, внутренние стороны — `antique-cover-v1.png`; `v2` сохранена как более декоративный вариант. Промпты в `docs/`.

Референс героини: `dist/assets/virtues-engraving-v1.png`. Правила серии — `docs/heroine-continuity.txt`.
