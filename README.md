# expert-book

Локальная книга «Методы подготовки эксперта».

Запуск из корня проекта:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Открыть http://127.0.0.1:4173/ . Исходники находятся в `dist/`; сборка не требуется.

В книге шесть разворотов: титульный лист, история возникновения, добродетели эксперта, рыцари круглого стола, испытание боем и защита перед советом ордена. Гравюры установлены; тексты глав пока предварительные.

Первое состояние при входе — закрытая кожаная обложка. Нажмите на неё или стрелку вправо, чтобы открыть книгу. После последней страницы следующее перелистывание закрывает заднюю обложку; стрелка влево возвращает к последней главе. Home и End переходят к передней и задней обложке. Оглавление открывает выбранную главу.

Ссылки `#cover` и `#back-cover` ведут к обложкам; существующие ссылки на главы открывают соответствующий разворот. На узком экране страницы отображаются по одной. Анимация учитывает настройку уменьшения движения и завершает переход при изменении размера окна.

Обложка — отдельный слой в `dist/book-covers.js` и `dist/book-covers.css`; состав разворотов и механизм бумажных страниц сохранены. Текстура и промпт: `dist/assets/antique-cover-v1.png`, `docs/antique-cover-prompt.txt`.

Референс постоянной героини: `dist/assets/virtues-engraving-v1.png`. Правила продолжения серии — `docs/heroine-continuity.txt`.
