# expert-book

Интерактивная книга «Методы подготовки эксперта».

Сайт: https://arevan.github.io/expert-book/

GitHub Pages публикует папку `dist/` через `.github/workflows/pages.yml`. Изменения в `dist/` после push в `main` публикуются автоматически; также доступен ручной запуск workflow. В Settings → Pages источником должен быть выбран GitHub Actions.

Запуск из корня проекта:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Открыть http://127.0.0.1:4173/ . Исходники находятся в `dist/`; сборка не требуется.

Шесть содержательных разворотов: титульный лист, история возникновения, добродетели эксперта, рыцари круглого стола, испытание боем и защита перед советом ордена. Гравюры установлены; тексты глав предварительные.

Первое состояние — закрытая кожаная книга без надписей, с тонкой рамкой и небольшим тиснением. Клик или стрелка вправо открывают передний форзац; следующее перелистывание открывает титульный разворот. После последней главы идут задний форзац и закрытие. Любой переход обратим. Home / End ведут к обложкам, оглавление — прямо к выбранной главе.

Хеши `#cover`, `#back-cover` — обложки; `#front-endpaper`, `#back-endpaper` — форзацы. Ссылки на главы сохранены. Форзацы не добавляют глав и не меняют нумерацию контента. На узком экране видна одна страница. Анимация учитывает уменьшение движения и безопасно завершается при изменении размера окна.

Переплёт: `dist/book-covers.js` и `dist/book-covers.css`. Активная наружная текстура — `dist/assets/antique-cover-v3.png`. Форзацы — цельный печатный лист с ботаническим орнаментом `dist/assets/endpaper-botanical-v1.png`: одно изображение 1120 × 700 проходит через обе половины. Переплёт общий для всех разворотов, без вложенных бордовых рамок. Бумажный блок разделён на две стороны: под вклейкой стопки нет, в том числе во время перелистывания к форзацу и обратно. Крышка и страницы используют точную геометрию одного рендера. `v1` и `v2` сохранены как ранние варианты. Промпты в `docs/`.

Титульная гравюра — `dist/assets/studies/title-forge-v1.png`: героиня с собранными волосами делает свои доспехи в кузне. Исходная кухонная иллюстрация сохранена в `dist/assets/cookbook-reference.png` как архивный референс.

Референс героини: `dist/assets/virtues-engraving-v1.png`. Правила серии — `docs/heroine-continuity.txt`.
