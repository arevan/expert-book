# expert-book
Repository for expert-book project


Локальная книга «Методы подготовки эксперта».

Запуск из корня проекта:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Открыть http://127.0.0.1:4173/ . Исходники приложения находятся в `dist/`; сборка и внешние зависимости не требуются.

Референс постоянной героини: `dist/assets/virtues-engraving-v1.png`. Её описание и правила продолжения серии — `docs/heroine-continuity.txt`.

Готовы титул, карта главы I и ангел главы II. Следующая иллюстрация — «Рыцари круглого стола». Главы III–V пока содержат места под новые гравюры.
